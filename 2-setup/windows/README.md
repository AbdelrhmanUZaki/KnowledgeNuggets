# Windows setup

Windows dotfiles and tools. Full fresh-install checklist: [Windows Setup.md](Windows%20Setup.md).

| Item | Purpose |
|---|---|
| `profile.ps1` | PowerShell 7 profile |
| `windows-terminal.json` | Windows Terminal settings (One Half Dark, Vim-friendly splits) |
| `kanata.kbd` | Keyboard remap: Esc → backtick, caps = Esc + scroll layer, space hold = nav arrows |
| `restore.ps1` | Symlink everything above (plus [`../shared/`](../shared/)) into your profile |

Cross-OS configs live in [`../shared/`](../shared/README.md).
